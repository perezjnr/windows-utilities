# Windows Utilities

A collection of utility and automation scripts for Windows, designed to simplify and enhance home lab environments. This repository provides tools and scripts to automate common Windows tasks, streamline system setup, and improve productivity for home labbers and enthusiasts.

## Features

- PowerShell scripts for system configuration and automation
- Batch files for quick fixes and repetitive tasks
- Tools for network management and monitoring
- Utilities for software installation and updates
- Customizable templates for common automation scenarios

## Getting Started

1. Clone this repository:
    ```sh
    git clone https://github.com/perezjnr/windows-utilities.git
    ```
2. Browse the scripts and read their individual documentation.
3. Run scripts with appropriate permissions (some may require administrator rights).
